# v0.6.1: pipe document formatting and dictionary setup

Accepted 2026-09-18. The user selected automatic document detection, prompt-based
preservation with one request and streaming, local dictionary installation plus
setup improvements, and release/Homebrew upgrade. The user explicitly selected
v0.6.1 instead of the initially suggested minor version.

## Document translation

- Add one-shot `--preserve-format`: true forces document translation, false
  disables it. Otherwise automatically detect multiline/Markdown stdin. Explicit
  `--preset` or `TRANSLATE_PRESET` wins over detection; forced preservation wins
  over presets. A plain word ending in a newline remains dictionary eligible.
- Add internal `engine.Request.PreserveFormat`. Use a dedicated faithful document
  prompt instead of contextual numbering/examples, preserving paragraphs, lists,
  tables, links and emphasis while leaving code/paths/URLs/identifiers unchanged.
- Use compatible pair instructions and local table guidance. Bypass SmartAuto's
  dictionary branch for forced document requests. Preserve ANSI-stripped input
  and response whitespace; only append a terminal newline when missing.
- Support JSON and streaming. Learn/bilingual disable automatic recognition;
  explicitly forcing incompatible modes is an error. Google retains engine
  selection and reports its format-preservation limitation.
- This is prompt-level preservation, without AST reconstruction or byte-level
  guarantees for the model's output. No config field/schema migration is needed.

## Dictionary setup

- Install this machine's CC-CEDICT and ECDICT with `translate dict update all`.
- After saving configuration, init inspects local data and offers Download now
  (default) or Later when data is missing, disclosing the ~67 MB download.
- Share update helpers; init downloads only missing sources. Existing Chinese
  raw data only needs `dict reindex` when its index is missing. Distinguish missing,
  healthy and unusable local data with read-only checks.
- Preserve saved settings and successful partial installation on cancel/failure;
  report retry commands and return nonzero on failure.
- Carry installation and source diagnostics through API/LLM fallback, including
  errors. Render Notes/Warnings on stderr; stdout remains translation or JSON.
  Show suggestion-only results rather than a blank line. Update help and README.
